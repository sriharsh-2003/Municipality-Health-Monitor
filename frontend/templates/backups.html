How This Works

Each backup is a single .zip file named with the exact date and time it was made, e.g. platform-health-backup_2026-09-21_143000.zip, so they sort chronologically and never overwrite each other.

The 30 most recent backups are kept automatically. Older ones are removed on a schedule so backups don't quietly fill up the laptop's disk over months of use.

To restore one: unzip it, then copy data/platform_health.xlsx and the data/attachments folder from inside it back into this app's data/ folder (with the app closed).
